# Capturas

Capturas reales de TolochaTracks tomadas en el AVD `Medium_Phone_API_37.0` con el tema
claro, una resolución de 1080 × 2400 y sesiones de ejemplo locales. No contienen rutas ni
datos personales reales.

| Archivo | Pantalla | Contenido |
|---|---|---|
| [`01-grabacion.png`](01-grabacion.png) | Grabar | Inicio de una ruta y selector de actividad. |
| [`02-historial.png`](02-historial.png) | Historial | Tres rutas de ejemplo, totales y filtros. |
| [`03-detalle.png`](03-detalle.png) | Detalle | Gráfico de distancia y parciales por kilómetro. |
| [`04-mapa.png`](04-mapa.png) | Detalle | Traza sobre OpenStreetMap y estadísticas. |
| [`05-ajustes.png`](05-ajustes.png) | Ajustes | Tema, exportación, mapas y calidad GPS. |

Las sesiones de ejemplo se inyectaron como JSON con el formato actual en el
almacenamiento privado de una compilación debug y se borraron del emulador al terminar.
Las capturas se optimizaron para que el README no pese de más; la de mapa usa una paleta
de 256 colores.

Para regenerarlas, sigue el procedimiento de
[`../desarrollo.md`](../desarrollo.md#capturas-para-la-documentación).
